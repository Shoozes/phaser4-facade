# 0.2.0 compatibility boundary

This document records the promoted runtime contract used by the current facade
candidate. It is a migration boundary, not a release or publication claim.

## Required consumer checks

- Use the namespaced `GM.*` API by default. Legacy GML-style globals are
  opt-in through `globals: true` and `phaser4-facade/legacy-globals`.
- Numeric colors remain GameMaker BGR values at facade boundaries.
- Rotation remains GameMaker degrees; `textExt` and `spriteExt` apply the
  expected counter-clockwise presentation.
- Fixed simulation is opt-in through `simulationHz`,
  `maxFrameDeltaMs`, and `maxCatchUpSteps`.
- Seeded randomness is opt-in through `randomSeed` or `GM.math.setSeed` and
  does not replace `Math.random`.
- Generated textures and atlases use `GM.asset.addCanvas`, `addRgba`, and
  `addAtlas`. Atlas frames may be ordinary objects, `Map` instances, tuples,
  or null-prototype maps.
- Multi-pointer consumers must use the pointer ownership helpers instead of a
  global joystick lock.

## New presentation helpers

`GM.draw.textExt`, `GM.gui.textExt`, `GM.draw.textFit`, and
`GM.gui.textFit` provide per-call presentation options. `GM.draw.spriteExt`
accepts both the old positional arguments and a fifth-argument options object.
The additions are additive; existing calls do not need to be rewritten.

## Optional Grout13 bridge

The package exposes `phaser4-facade/grout13` and corresponding global files.
The bridge requires a consumer-supplied object with
`compileGrout13Atlas()` and `decodeGrout13Atlas()` functions:

```js
import { GM } from "phaser4-facade";
import { installGrout13Bridge } from "phaser4-facade/grout13";
import * as GROUT13 from "grout13";

installGrout13Bridge(GM, GROUT13);
GM.grout13.addAtlas("fruit-atlas", assets, {
    compileOptions: { runtimeTarget: "canvas" }
});
```

The bridge validates decoded canvas/frame data and delegates registration to
the existing `GM.asset.addAtlas` API. It does not import Grout13 into the core
bundle, execute generated scripts, fetch data, or grant a consumer a network
or model boundary.
